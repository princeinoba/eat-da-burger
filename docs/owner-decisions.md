# Owner decisions before wider public promotion

## Required or recommended decisions

1. Approve **BurgerForge AI** as the public product name.
2. Decide whether the existing `princeinoba/eat-da-burger` repository should be modernized or whether a new repository should be created.
3. Clarify the historical licence discrepancy: package metadata says ISC, README says MIT, and the archive has no licence file.
4. Select a licence for the clean-room source before third-party redistribution.
5. Review the eight curated burger concepts and food-safety wording.
6. Decide whether optional live AI should be enabled.
7. When enabling live AI, approve:
   - Vercel AI Gateway use;
   - the current model ID;
   - provider terms;
   - spend/budget controls;
   - public abuse controls;
   - evaluation cases.
8. Decide whether the site should remain noindex or become normally indexable.
9. Approve the stable Production domain or a future custom domain.
10. Decide whether a future release needs accounts and cloud synchronization.
11. Do not add verified nutrition or allergen claims without an authoritative food-data source and expert review.

## Safe initial release decisions already implemented

- No account.
- No database.
- No payment or ordering.
- No automatic save.
- No verified nutrition or allergen claims.
- Deterministic fallback remains available.
- Board and notes remain local.
- Public site remains noindex.
